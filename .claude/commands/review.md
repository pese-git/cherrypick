description: Ревью текущей ветки или PR CherryPick — CI локально и ревью кода и публичного API
argument-hint: [change-id, номер PR или фокус ревью]
---
Контекст: $ARGUMENTS

1. Определи diff: `git diff develop...HEAD` плюс незакоммиченное; для номера PR — `gh pr view`/`gh pr diff` (ветку переключай только с согласия пользователя). Найди связанный OpenSpec change.
2. Параллельно: **check-runner** (затронутые пакеты; нижняя версия матрицы — если менялись SDK, analyzer или плагин), **code-reviewer**, **api-reviewer**. Если затронут горячий путь резолва — **benchmark-engineer** для замера.
3. Покажи пользователю: таблицу проверок, вердикты, сводный список замечаний (сначала BLOCKER), ожидаемый semver-бамп пакетов и задетых потребителей.

Ничего не исправляй без просьбы. Если пользователь попросит — раздай замечания исполнителям по зонам и повтори ревью.
