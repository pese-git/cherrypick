## Почему CherryPick 2.x?

<CardGrid stagger>
  <Card title="Sync и async" icon="random">
    Регистрируйте и получайте синхронные фабрики, асинхронные провайдеры (`toProvideAsync`) и уже запущенные Future (`toInstanceAsync`).
  </Card>
  <Card title="Именованные и параметризованные" icon="setting">
    Привязывайте несколько реализаций под именами и создавайте зависимости из runtime-параметров.
  </Card>
  <Card title="Аннотации и кодогенерация" icon="pencil">
    Описывайте модули и field injection аннотациями; `cherrypick_generator` сгенерирует связывание.
  </Card>
  <Card title="Иерархические скоупы" icon="list-format">
    Стройте дерево именованных скоупов с путями через точку, изолируйте зависимости и закрывайте целые поддеревья.
  </Card>
  <Card title="Опциональное получение" icon="approve-check">
    Используйте `tryResolve` / `tryResolveAsync`, чтобы получить `null` вместо исключения при отсутствии зависимости.
  </Card>
  <Card title="Интеграция с Flutter" icon="puzzle">
    Пробрасывайте DI-скоуп в дерево виджетов через `CherryPickProvider` — или используйте ядро в чистом Dart.
  </Card>
</CardGrid>

## Установка

<Tabs>
  <TabItem label="Dart">

```yaml title="pubspec.yaml"
dependencies:
  cherrypick: ^2.2.0
  cherrypick_annotations: ^2.2.0

dev_dependencies:
  build_runner: ^2.0.0
  cherrypick_generator: ^2.2.0
```

  </TabItem>
  <TabItem label="Flutter">

```yaml title="pubspec.yaml"
dependencies:
  cherrypick: ^2.2.0
  cherrypick_flutter: ^2.2.0
  cherrypick_annotations: ^2.2.0

dev_dependencies:
  build_runner: ^2.0.0
  cherrypick_generator: ^2.2.0
```

  </TabItem>
</Tabs>
