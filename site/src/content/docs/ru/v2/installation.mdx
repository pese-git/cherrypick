import { Tabs, TabItem } from '@astrojs/starlight/components';

Добавьте CherryPick в `pubspec.yaml`. Пакеты `cherrypick_annotations` и
`cherrypick_generator` нужны только если вы используете аннотации и кодогенерацию.

<Tabs>
  <TabItem label="Dart">

```yaml title="pubspec.yaml"
dependencies:
  cherrypick: ^2.2.0
  cherrypick_annotations: ^2.2.0

dev_dependencies:
  build_runner: ^2.0.0
  cherrypick_generator: ^2.2.0
```

  </TabItem>
  <TabItem label="Flutter">

```yaml title="pubspec.yaml"
dependencies:
  cherrypick: ^2.2.0
  cherrypick_flutter: ^2.2.0
  cherrypick_annotations: ^2.2.0

dev_dependencies:
  build_runner: ^2.0.0
  cherrypick_generator: ^2.2.0
```

  </TabItem>
</Tabs>

Установите пакеты:

```sh
dart pub get      # или: flutter pub get
```

Если используете аннотации, запускайте генератор при каждом изменении DI-кода:

```sh
dart run build_runner build --delete-conflicting-outputs
```

Импортируйте ядро там, где настраиваете зависимости:

```dart
import 'package:cherrypick/cherrypick.dart';
```
