## Getting help

- Ask questions and discuss ideas in the [Telegram chat](https://t.me/+22IVT0vqXBg1NDdi).
- Report bugs and request features in [GitHub issues](https://github.com/pese-git/cherrypick/issues).

## Contributing

Contributions are welcome — bug reports, documentation fixes, and pull requests alike.
All packages live in a single [GitHub repository](https://github.com/pese-git/cherrypick),
managed as a [Melos](https://melos.invertase.dev) workspace.

1. Open an issue first for anything larger than a small fix, so the approach can be agreed on.
2. Fork the repository and make your change in the relevant package.
3. Add or update tests, and run `dart analyze` and the package tests.
4. Open a pull request describing what changed and why.

This documentation site lives in the `site/` directory of the same repository; every
page has an **Edit page** link at the bottom.
