## Building blocks

<CardGrid>
  <Card title="Binding" icon="setting">
    Configure how a dependency is created — `toInstance()` for a ready value or `toProvide()` for a factory, with optional `withName()` and `singleton()`.
  </Card>
  <Card title="Module" icon="puzzle">
    A container of bindings. Extend `Module` and register your dependencies inside `builder(Scope currentScope)`.
  </Card>
  <Card title="Scope" icon="list-format">
    A container that holds the whole dependency tree. Resolve instances with `resolve<T>()` and nest scopes with `openSubScope()`.
  </Card>
</CardGrid>

## Features

- Root and nested (sub) scopes
- Named instances
- Singleton and factory bindings
