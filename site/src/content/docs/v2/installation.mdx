---
title: Installation
description: Add CherryPick 2.x and set up code generation.
---

import { Tabs, TabItem } from '@astrojs/starlight/components';

Add CherryPick to your `pubspec.yaml`. Include `cherrypick_annotations` and
`cherrypick_generator` only if you plan to use annotations and code generation.

<Tabs>
  <TabItem label="Dart">

```yaml title="pubspec.yaml"
dependencies:
  cherrypick: ^2.2.0
  cherrypick_annotations: ^2.2.0

dev_dependencies:
  build_runner: ^2.0.0
  cherrypick_generator: ^2.2.0
```

  </TabItem>
  <TabItem label="Flutter">

```yaml title="pubspec.yaml"
dependencies:
  cherrypick: ^2.2.0
  cherrypick_flutter: ^2.2.0
  cherrypick_annotations: ^2.2.0

dev_dependencies:
  build_runner: ^2.0.0
  cherrypick_generator: ^2.2.0
```

  </TabItem>
</Tabs>

Fetch the packages:

```sh
dart pub get      # or: flutter pub get
```

If you use annotations, run the generator whenever your DI code changes:

```sh
dart run build_runner build --delete-conflicting-outputs
```

Import the core library where you configure dependencies:

```dart
import 'package:cherrypick/cherrypick.dart';
```
